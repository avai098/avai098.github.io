这是一篇用来测试**长时间阅读舒适度**的技术长笔记样张。
## 1. 为什么我们需要版本控制？ 在没有版本控制的年代，我们修改文档通常会保存为： 
- `报告_最终版.doc`
- `报告_打死不改版.doc` 
- `报告_最终真没改版.doc` 

版本控制工具彻底解决了这个问题。 
### 1.1 分布式与集中式 Git 属于分布式版本控制系统，每台电脑都是一个完整的代码库。 

## 2. 常用基础命令 下面是日常使用中最频繁的三个命令：

```bash 
# 查看当前工作区状态
 git status 

# 将修改添加到暂存区 
git add .
 
# 提交并附带说明 
git commit -m "feat: 完善了阅读排版配置"
```
